函数指针可以替换一个操作，而设备通常需要一组相关操作。例如 LED 有开启、关闭、亮度设置和释放资源；文件有打开、读取、写入和关闭；网卡也有启动、停止和发送等操作。

本节将这些相关函数指针放进一个结构体，称为操作表，通常命名为 ops。

操作 GPIO LED PWM LED
on 输出高电平 设置 PWM 占空比
off 输出低电平 将占空比设为 0
set_brightness 保存数值，并按零与非零设置开关 设置或保存占空比
deinit 释放 GPIO 配置 按资源约定停止或释放 PWM

可以把一组实现集中存放，由对象记录使用哪一组。

这种操作表与 C++ 实现虚函数调用时常用的虚函数表（vtable）用途相近。这里的表和分发过程由 C 代码显式定义，具体的类型检查和接口约定也需要自行处理。

将操作表用于其他接口

同样的组织方式可以用于存储驱动的 read/write/erase、通信接口的 send/recv/ioctl、文件系统的 open/read/write/close，以及网络设备的 open/stop/transmit。

当新硬件能够遵循现有接口约定时，可以增加对应的操作表及实现，让上层继续使用相同接口。
